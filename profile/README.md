FreightVerse builds open-source software for logistics: brokers, shippers, carriers and 3PLs.
Everything we ship is open source, self-hostable and API-first.

### Products

| | Product | What it is |
|---|---|---|
| <img src="assets/vecto-mark-light.svg" width="20" alt=""> | **[Vecto](https://github.com/Freight-Verse/vecto)** | The open-source TMS, built on Frappe and ERPNext. MCP-first, with a built-in chat assistant. |
